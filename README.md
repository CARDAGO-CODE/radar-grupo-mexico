# Radar de Grupo México

Proyecto web de consulta de oportunidades comerciales de Grupo México.

## Abrir el proyecto

Descarga o clona el repositorio y abre `index.html` en Chrome, Edge o Safari. Conserva la estructura de carpetas para que funcionen las imágenes, la navegación y las descargas.

## Contenido

- `index.html`: agenda comercial y entrada al sitio.
- `Oportunidades_Grupo_Mexico.html`: detalle de oportunidades.
- `Potencial_Comercial_Grupo_Mexico.html`: potencial comercial.
- `Rutas_Comerciales_Grupo_Mexico.html`: rutas comerciales.
- `Plan_30_Dias_Grupo_Mexico.html`: plan de trabajo.
- `imagenes/`: fotografías utilizadas en el sitio.
- `propuestas/`: 16 propuestas comerciales editables en PowerPoint.
- `Radar_Grupo_Mexico_Completo.xlsx`: archivo de trabajo en Excel.
- `Transcripcion_Grupo_Mexico.md`: transcripción de referencia.

Las propuestas son borradores para revisión del socio, con honorarios y tiempos por acordar. Consulta `LEEME.txt` para las instrucciones del Excel.
